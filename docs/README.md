## 自己PR・強み

1. **アーキテクチャ最適化による事業成果創出（コスト・速度）**
   与えられたシステム構成や制約の中でボトルネックを正確に特定し、技術的アプローチによって事業利益を最大化します。MAプロジェクトでは、Trino導入により1,600万円のコストを削減しました。DynamoDB最適化では処理時間を1/3に短縮し、コストを50%削減しました。

2. **「引き算のエンジニアリング」による組織生産性とDX（開発体験）の向上**
   認知負荷や開発ノイズを減らすアプローチを得意としています。形骸化したアラートチャンネルの整備やデッドコード削除、不要なミーティングの削減を徹底し、チーム全員が日々の開発に没頭できる環境（1日8時間集中できる体制）を構築・推進しました。

3. **「ビジネス納期・品質・収益（MRR/CVR）」を意識した開発遂行力**
   技術追求にとどまらず、常にその先にある「事業価値」を最優先に考えます。CDP開発ではエンタープライズ案件の厳しい納期を守り抜いてMRR拡大に寄与し、ECカート運用では購入画面のレスポンス改善によりユーザー離脱を防ぎ解約抑止（CVR向上）を達成しました。

4. **ナレッジ共有と組織貢献**
   プロジェクト参画時にはゼロからオンボーディングドキュメント（アーキテクチャ図・データフロー図）を整備し、後続メンバーのキャッチアップコストを大幅削減。社内テックブログの立ち上げ・執筆を主導するなど、ナレッジの言語化とチーム・組織全体のスキル底上げにもコミットしています。

## 技術スキル・レベル

- **Ruby on Rails:** 大規模・長期運用システムの機能開発、本番障害対応、パフォーマンス改善、フレームワークのバージョンアップ（セキュリティリスク低減・動作保証担保）を主導できます。
- **SQL:** `EXPLAIN`で実行計画と適用インデックスを確認し、ORMに依存せず生SQLでクエリ解析・パフォーマンス改善ができます。
- **DynamoDB:** GSIの設計・作成・削除およびアクセスパターンの見直しにより、ホットキー問題の解消やスループット最適化に対応できます。
- **Serverless Framework:** 標準キューおよびFIFOキューを利用した耐障害性の高い配信基盤を設計・運用できます。
- **Ruby:** `method_missing`や動的メソッド定義を含むメタプログラミングを解読・理解しており、内部DSLやライブラリ設計に活用できます。
- **GraphQL・React:** graphql-batchやApollo ClientによるN+1対策に対応。フロント・バックエンド間の疎通設計や`useState`・`Provider`を活用した状態管理を実装できます。
- **MySQL:** インデックス最適化、クエリチューニング、ActiveRecordの逆引き改善、高負荷下でのスロークエリ改善に対応できます。
- **CI/CD・監視・品質:** GitHub ActionsやCircleCIを構築できます。New Relic / CloudWatchによる調査・改善にも対応できます。負荷試験環境とリグレッションテスト自動化による無障害リリース体制を構築できます。
- **テスト・レビュー:** RSpecの設計、FactoryBotによるデータ設計、仕様不整合を早期検知するコードレビューの実践が可能です。
- **決済ドメイン:** クレジットカード、後払い、アプリ決済の仕様・トークン連携・サーバーサイド処理およびデータ保持モデルを熟知しています。
