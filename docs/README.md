## 自己PR・強み

1. **事業価値を意識したプロジェクト推進**
   納期、品質、MRR、CVRを意識し、要件定義からリリースまでを推進できます。エンタープライズ案件の導入完遂、インフラコスト1,600万円削減、配信処理時間の3分の1短縮など、事業成果につながる改善を実現しました。

2. **障害を予防する安定運用**
   障害発生後の対応だけでなく、過去の障害やログを調査して再発防止につなげます。負荷試験、テスト自動化、アラート最適化によって、プロジェクトを炎上させない運用体制を構築します。

3. **プレイヤーとリードの両立**
   メンバー、開発リーダー、テックリード、FDEなど、状況に応じたロールでチームに貢献できます。POとの調整、タスクアサイン、QA稼働の逆算、差し込みタスクの吸収により、メンバーが開発に集中できる状態をつくります。

4. **複雑さを減らす仕組みづくり**
   不要な会議の削減、アラートチャンネルの整理、デッドコード削除、ドキュメント整備、オンボーディング体制の構築を推進します。社内テックブログの立ち上げ・執筆を通じたナレッジ共有にも取り組みました。

## 技術スキル・レベル

- **Ruby on Rails:** 大規模・長期運用システムの機能開発、障害対応、パフォーマンス改善、フレームワークのバージョンアップを主導できます。
- **SQL:** `EXPLAIN`で実行計画と適用インデックスを確認し、ORMに依存せず生SQLで調査・改善できます。
- **DynamoDB:** GSIの設計・作成・削除と書き込みパターンの見直しにより、ホットキー問題を解消できます。
- **Serverless Framework:** 標準キューおよびFIFOキューを利用した配信基盤を設計・運用できます。
- **Ruby:** `method_missing`や動的メソッド定義を含むメタプログラミングを理解しています。内部DSLやライブラリーの解読・設計に活用できます。
- **GraphQL・React:** graphql-batchやApollo ClientによるN+1対策に対応できます。フロントエンドとバックエンド間の疎通設計や、`useState`・`Provider`を使った状態管理を実装できます。
- **MySQL:** `EXPLAIN`による実行計画の解析、インデックス最適化、クエリチューニング、ActiveRecordの逆引き改善に対応できます。
- **CI/CD・監視:** GitHub Actions、CircleCI、Jenkinsの構築・運用、New RelicやCloudWatchによるトレース解析・障害調査を経験しています。
- **テスト・レビュー:** RSpecの`context`・`it`設計、FactoryBotによるテストデータ設計、例外・仕様不整合を早期検知するコードレビューを実践できます。
- **決済ドメイン:** クレジットカード、後払い、アプリ決済の仕様、決済トークン連携、サーバーサイド処理、データ保持モデルを理解しています。
